Options Plotter — Interactive Sharing update

1. Replace your current desktop .py with Options_Plotter_Pro_v12_10_3_Interactive_Share.py.
2. Upload share.html to the ROOT of the optionsplotter.com website so that https://optionsplotter.com/share.html resolves.
3. Launch the Python application (requires matplotlib). Configure a trade and click Copy Link, X, or Reddit under Share This Trade.
4. Recipients can drag the P&L chart price dot and move the date slider in a browser without installing software or creating an account.
5. Export PNG in the desktop app exports the existing Matplotlib chart.

Links encode the trade details in the URL fragment. No cloud database or user accounts are needed. URLs can be long, especially with many legs. Shared quotes/premiums are a snapshot; they do not refresh automatically. No changes to existing IBKR, quote, pricing, or order logic.
